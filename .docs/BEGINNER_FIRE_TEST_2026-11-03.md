# CoChem class tryout: Tuesday 3–Friday 6 November 2026

Use this guide with [Your first CoChem calculation](FIRST_LAB.md) and the task
your instructor assigned. Use only the molecule, settings and calculation route
your instructor has approved. An unavailable engine or an unclear status is a
reason to keep your work and ask for help, not to guess different settings.

| Day | Small goal |
| --- | --- |
| **Tuesday 3 November** | Open the workspace. Find **1 · Setup** and **2 · Add your molecule**. Check the available route, keep your original input file, and select the intended structure. |
| **Wednesday 4 November** | Follow **3 · Run assigned calculation** for the assigned task. Read the status before clicking again. If a job is waiting, running or uncertain, check that same job rather than submitting another copy. |
| **Thursday 5 November** | Use **4 · Read and save results** for completed work. Check its task, units and warnings. Save the offered calculation files to your own computer. Follow the first-lab instructions for reopening; a downloaded ZIP does not restore workspace history. |
| **Friday 6 November** | Tell your instructor what worked and what blocked you. Report one problem clearly using the prompts below. Keep the original input and result records. |

If you need to stop work, use **Stop running jobs** and wait for confirmed final
statuses before starting a replacement. Keep an uncertain request and its message
for your instructor. A stop request is not confirmation that the job has ended.

## A useful problem report

Write down the step, what you expected, what actually happened, and the last few
buttons you clicked. Add your browser/device if you know them. You do not need
programming or scientific troubleshooting expertise to report a problem.

Use the **private reporting route your instructor provided** for private project
links, molecular files, coursework, full diagnostic messages or screenshots with
personal information. If no route has been provided, ask your instructor how to
send the report privately. Do not send passwords or access tokens, even privately.

For a report that contains no private information, use the
[public beginner bug form](https://github.com/ProfJJK-CoChem/CoChem-BASE/issues/new?template=beginner_lab_problem.yml).
A public-safe run link or cropped screenshot is optional. Check that it reveals
no account details, private repository names, file paths, molecules or coursework.
If you are unsure, use the instructor-private route. No email address is required.

This tryout gathers feedback on the available workflow. It does not certify a
calculation's scientific accuracy, that every engine is available, or that a
missing result can be reconstructed after its original files are removed.
