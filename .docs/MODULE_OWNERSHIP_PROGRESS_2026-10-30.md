# Canonical module ownership: bounded implementation and remaining gates

This increment removes foreign TOPOS/TORQ namespaces from BASE wheels and source
archives and delegates TORQ science to its canonical installed provider. It does
not establish completed source migration, full SRS conformance, or student readiness.
The [ownership audit](Module_Ownership_Audit_2026-10-18.md), complete SRS and
[completion backlog](WORKSTATION_COMPLETION_HANDOFF.md) still apply.

BASE retains its Chunk 17 REQ-BASE-006 conformer and proposal §3.14 CREST/GOAT
responsibilities. The orchestrator and quench broker now live under
`cochem_base.intake`; the old source paths are deprecated, unshipped shims.
The scientific algorithms and thresholds were preserved. Isolated provider
execution continues to implement WBS 17.1.3 and proposal §3.3.

The catalog selects published canonical TORQ
`19fded21c1a579d9226077d072dd876cac7be484`. BASE transports geometry, rigid-scan
and Löwdin requests through its versioned entry point, verifies installed source,
runtime and returned artifact identities, and contains no second implementation
of those operations. NBO/NAO remain unavailable when their qualified provider is
absent. Löwdin indices are not labeled as NAO Wiberg indices.

Independent review verified the unchanged source for the successful 33-check
transport/ownership producer, three genuine managed TORQ operations and 24 native
artifact hashes. The rigid water-dimer scan retained 3.0 and 3.2 Å mass-COM
separations within 1e-12 Å. These bounded HF/STO-3G cases establish execution and
transport; they do not establish chemical accuracy or a student Actions pilot.
A separate real-wheel negative run refused altered provider bytes and ambiguous
entry points. Historical failed test setup and nonconverged native input evidence
remain retained; they are not counted as passes.

Four Lewis-graph/isotope test functions and their helper moved byte-for-byte with
five scientific modules to canonical TOPOS's local candidate
`eecff25b13343305a3f05310800503014667e80a`. Its frozen profile completed with
2850 passed and 43 explicitly skipped; separate installed structural checks passed
127 with no skips. This candidate is **not yet published**. BASE's TOPOS catalog
pin therefore remains unchanged pending publication, a compatible clean BASE
foundation and actual managed integration acceptance.

All five BASE empirical-quench test bodies and their helper remain byte-for-byte
unchanged. Fresh real wheel/source-archive ownership checks passed 2 cases. The
five quench cases passed from the source checkout and from the extracted source
archive. An additional origin-recording run of those same five cases verified all
11 loaded BASE/test modules came from the extracted archive, without a bundled
provider namespace or source changes. Repeated execution is not additional unique
scientific coverage. Portable review records, original XML and hashes are in
[evidence](evidence/module-ownership-progress-20261030/packaging-and-quench-review.json).

Remaining gates include the 92 retired namespace files still tracked in BASE,
supplementary tests and active shared `Libraries`, publication of canonical TOPOS,
a new compatible BASE science foundation, and installation/operation acceptance
through the actual managed installer. The source copies are excluded from both
release formats; they are not approved alternate scientific implementations.
Do not delete them or their unresolved obligations without completing the upstream
transfer. Current GitHub access must be restored before fetching current remote
heads or publishing this increment. Independent student histories and data remain
outside this change.
