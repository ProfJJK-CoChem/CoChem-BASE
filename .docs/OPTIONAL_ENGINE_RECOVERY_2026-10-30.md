# Optional engine failure and recovery

A new remote availability check now withdraws the previous observation before
starting. Authentication, download or probe failure leaves ORCA/CFOUR unavailable
and presents a retry action. Delayed failures for an earlier project cannot
replace the current project's state. Retrieved job diagnostics cannot manufacture
a positive provisioning observation.

When a licensed selection disappears, the interface requires an explicit new
choice. It does not silently substitute another engine, recipe or orbital method.
Already selected free methods remain selected. ORCA/CFOUR remain optional and
strongly recommended; BASE input inspection and unrelated supported work remain
available.

The [qualification record](evidence/optional-engine-recovery-20261030/qualification.json)
binds the exact production/test hashes and limits. Eight optional-engine controls
and six research controls passed without skips. Synthetic prior-state controls
exercise withdrawal and selector admission only, and are identified separately
from real browser and native execution evidence. The additional committed-source
quarantine gate remains required before release acceptance.

The final GUI was exercised in Chromium with an actual upload and two real failed
GitHub checks through the check/retry buttons. Licensed choices stayed absent,
the existing free xTB selection stayed available, and the original upload hash
remained unchanged. Browser and request errors were both zero.

A local GUI GFN2-xTB water optimization converged at -5.070544447821 Eh. Its
producer differs from the final GUI by one additional operation-selection
observer; the final GUI was checked separately without rerunning that chemistry.
The [native bundle](evidence/optional-engine-recovery-20261030/native-water-xtb.tar.gz)
retains original inputs, analytic gradients, every optimization evaluation and
native outputs; its inventory binds each original byte stream. This is a screening
calculation with explicitly recorded convergence scope, not strict-quintuple,
reference-accuracy, hosted ORCA/CFOUR or student acceptance.

The independent review and screenshots are retained with hashes. This increment
does not close the separate same-browser widget recovery observation after a
service restart, the actual student Codespace pilot, current GitHub authorization,
private controller billing, or the full SRS backlog.

The exact original upload is retained outside the application source and in its historical Git blob, as recorded in [original-upload-storage.json](evidence/optional-engine-recovery-20261030/original-upload-storage.json). Its redundant raw XYZ copy was removed from the current source plane to meet the unchanged airgap policy. The 289-member native result bundle is unchanged and does not contain those exact original upload bytes. Historical receipts and their original file hashes remain intact.
